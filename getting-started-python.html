YOUR NEXT CODING ADVENTURE

Little lines. Big ideas.

Make pictures, play with words, and build a game! In Python, you type instructions for your computer. We’ll use the Raspberry Pi Code Editor to bring them to life.

STEP 1 · GET READY

Your browser is your coding playground.

Grab a parent or carer for the account setup. Here’s what you’ll need:

  • A computer with internet
  • A keyboard and a web browser
  • A grown-up’s help and email inbox
  • A fun username and secret password

The Raspberry Pi Code Editor is free and runs in your browser. For the projects below, you don’t need to install Python or own a Raspberry Pi computer.

STEP 2 · MAKE YOUR ACCOUNT

Give your creations a home.

A Raspberry Pi Foundation account lets you save your code and carry on another day. This is a separate account from Scratch.

Open the Code Editor ↗
  1. Find the account button. Choose Sign up, or choose Log in and then Create one.
  2. Choose the right age option together. If you’re under 13, your parent or carer should choose Under 13 and set up the account with you, using their email address. If you’re 13 or older, follow the signup instructions for your age.
  3. Invent a username. Something like MoonRobot27 is great. Keep your real name out of it. Make a strong password with your grown-up and ask them to keep it safe.
  4. Finish the form and check the email. Follow the verification link sent to the email address you used. Look in the junk folder if it hasn’t arrived.
  5. Return to the editor and log in. Keep your login details safe for your next club session.

Already have a Raspberry Pi Foundation account? Try logging in with that. You can also try coding before signing up, but ask a helper about saving your work before you close the page.

STEP 3 · MEET YOUR EDITOR

Type it. Run it. See what happens!

Pick one of the projects below and follow its link to the starter code. A starter project has some code or pictures ready for you, so you can jump into the fun.

  1. Read one small step in the project guide.
  2. Type the code where it shows you. Check capital letters, quotation marks and spaces at the start of lines. They matter in Python!
  3. Click Run. Look at the output to see what your program does.
  4. Experiment. Change a message or a colour, then run it again.

An error message is a clue, not a score! Check the line it mentions, compare it with the guide, and ask a helper if you’re stuck. Every coder fixes mistakes.

STEP 4 · CHOOSE AN ADVENTURE

Say hello. Then take aim!

These Raspberry Pi projects use the browser Code Editor. Start with Hello world if you’re new to Python. Try Target practice when you’re ready for a bigger challenge.

There are lots more adventures to choose from. Check each project’s “What you will need” section with a helper: some other projects use extra equipment or different software.

Keep your guide close by.

Some projects show the instructions right beside the code. If the guide offers that layout, give it a try! Otherwise, keep the guide and editor in separate tabs. Click the guide’s tab to read a step, then the editor’s tab to try it.

Want both tabs side by side in Chrome?

With the editor selected, right-click the project guide’s tab. Choose New split view with current tab. You can now read and code beside each other. Drag the divider to make more room.

To return to separate tabs, use the split view icon beside the address bar and choose Separate split view. If that option isn’t available, just switch tabs as you go.

STEP 5 · KEEP YOUR CREATION

Save today. Create more tomorrow.

Check that you’re logged in. Use the editor’s save option if prompted, give your project a name you’ll recognise, and check that it shows your work is saved before closing it. Ask a helper to help you find it in your saved projects.

If you haven’t made an account yet, ask a helper to use the editor’s download option to keep a copy on the computer. Remember where you put it!

When you finish on a shared club computer, log out of your account. Next time, log in again to carry on with your saved creations.
